# 会话语义决策(显式化,不假装)

> 目标:OpenLab 有的会话操作在 dsh v1 下没有原生对应 —— 每一项都必须三选一
> (等待上游 / DeepLab 显式降级语义 / 暂缓),并写清 UI 如何表现。日期:2026-09-06。

| 操作 | dsh v1 | DeepLab 决策 | UI 表现 |
|---|---|---|---|
| 会话删除(永久) | 无 delete RPC | **降级**:用 archive 移出活跃列表;永久删除不做 | 侧栏“归档”;被归档项移出列表(可经历史/工作区找回) |
| 恢复已归档 | 无 restore | **暂缓/降级**:已归档会话仍在磁盘与转录中,可在历史/工作区重新打开;不提供“取消归档”按钮 | 会话入口仍列出(标 archived),点开即重新 attach |
| 编辑历史消息 / revert | 无 | **降级**:隐藏 revert;引导 fork | 消息无编辑入口;提供“由此处 fork” |
| 队列 | 无 queue 状态 | 本地草稿箱语义:队列在客户端持久化,按 `mode:"queue"` 逐条提交;不代表 dsh 权威 | QueuePanel 明确为本地草稿 |
| jobs/后台任务 | 无 | **隐藏**:不提供 jobs 入口 | 无此 UI |
| `/plan` 计划模式 | 无 plan 域 | 用 agent 预设 + 会话内 steps 表达“先计划后执行”;不复刻 OpenCode 计划投影 | “执行步骤”面板;无 plan 模式开关 |
| OAuth 登录 | 无 | 不支持:凭据走 Settings(credentials) | 无 OAuth 入口 |
| 应用自更新 | — | 暂缓(发布成熟后再接) | 无 |

原则:凡 dsh 无对应能力 → 隐藏或显式降级,**绝不伪造状态**;能力可用 → UI 才展示。
